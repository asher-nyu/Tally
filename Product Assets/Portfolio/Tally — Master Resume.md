Tally: Native Cash Flow Planning for iPhone, iPad, and Mac With Custom Recurring Schedules, iCloud Documents, and On-Device Reminders
Sep 2026 – Present

● Designed and built Tally using Swift 6 and SwiftUI, sharing financial models and scheduling logic across iOS, iPadOS, and macOS while integrating UIKit and AppKit for native document browsing, window management, editing, and system interactions
● Developed monthly and annual cash-flow views that calculate scheduled income, expenses, and net cash flow from actual occurrences within each period, accounting for three-paycheck months, annual subscriptions, one-time payments, and variable amounts excluded from fixed totals
● Engineered a calendar-based recurrence engine supporting daily, weekly, monthly, and yearly intervals, selected weekdays and dates, ordinal patterns such as the last Friday, and optional end dates; handled month-end clamping, leap years, duplicate occurrences, and months without a fifth weekday
● Implemented exact monetary parsing and formatting using integer minor units, locale-aware decimal and grouping rules, currency-specific precision, and overflow validation, avoiding binary floating-point calculations in stored amounts and financial totals

● Implemented three-way document merging to combine independent changes and preserve competing edits as explicitly marked copies; rebased undo operations onto the latest document state so incoming changes remain intact
● Developed file-lifecycle handling with NSFileCoordinator, NSFilePresenter, filesystem event monitoring, and security-scoped resource access, supporting external moves, Trash restoration, recovery copies, permanent deletion, and atomic file replacement while preserving other open documents
